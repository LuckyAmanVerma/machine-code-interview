# Machine Code Interview

## Project Overview
The "Machine Code Interview" project is a React application built using Vite as the bundler. It serves as a platform for practicing and preparing for coding interviews, focusing on data structures and algorithms.

## Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd machine-code-interview
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to view the application.

## Usage
- The application is structured to allow easy navigation between different components and pages.
- You can add new components in the `src/components` directory and new pages in the `src/pages` directory.
- TypeScript types and interfaces can be defined in the `src/types` directory for better type safety across the application.
